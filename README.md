# Вертикальный ролик 9:16 с TikTok-субтитрами (Remotion)

- Распознавание русской речи по словам: GigaAM v2 (sherpa-onnx) + Silero VAD.
- Субтитры: Montserrat ExtraBold, по 1–3 слова, текущее слово подсвечено пыльно-розовым (`src/theme.ts`).
- Отступ субтитров снизу — `captionBottom` (по умолчанию 340 px, не меньше 170) в `src/Root.tsx`.
- Камера: плавное приближение/отдаление и короткий наезд в начале каждой фразы; виньетка, прогресс-бар, появление/затухание.

```bash
scripts/setup.sh                 # один раз
scripts/make.sh нейропрофи/моё-видео.mp4  # -> нейропрофи/моё-видео-9x16.mp4
npm run studio                   # предпросмотр и подстройка
```

Если исходник горизонтальный, кадр обрезается по центру; сдвиг — `focusX` (0–100). Точка наезда камеры — `zoomOriginY`.
